# Moment Scope — Public Media Delivery

This repository is reserved for **individual, approved video release assets** so the existing connected Metricool publishing workflow can retrieve a direct video file URL.

No private source code, tokens, raw research, or unfinished source footage belongs here. A release is created only after documented permission to distribute the exact finished media, source reuse rights, audiovisual review, and zero-extra-spend verification.

Public GitHub release assets are publicly accessible; **publication to YouTube, Instagram or TikTok is a separate approval step**. Production code remains private in `MomentScope/moment-scope-video-pipeline`.

Do not add a GitHub Actions workflow here. This companion repository is a passive file delivery host only.
